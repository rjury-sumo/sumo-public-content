# Mobot prompt examples

## Overview

Mobot is Sumo Logic's conversational assistant for working with your observability and security data. Dojo AI agents extend AI-powered assistance for SOC workflows. Learn more about [Dojo AI agents](https://www.sumologic.com/blog/welcome-dojo-ai-agents-soc).

## Prompt examples

- [Create prompts from a prompt](1.Use_a_prompt_to_make_more_prompts.md) — Generate new prompts tailored to a task or use case.
- [Discover and profile a log source](2.discover_and_profile_log_source.md) — Identify a log source, inspect sample events and metadata, and summarize its schema and use cases.
- [Create a training lab](3.build_training_content_and_labs.md) — Build beginner-friendly training material with practical search exercises for a selected log source.
- [Billable scan remediation report](4.analyze_billable_scan_remediation_report.md) — Find high billable-scan usage and recommend remediation for the largest contributors.
- [Executive search usage report](5.evaluate_business_value_core_use_cases.md) — Summarize search volume, users, scan usage, and billing-tier context for an executive audience.
- [Partition volume analysis and guidance](6.Partition_Volume_Analysis_and_Re-Partitioning_Guidance.md) — Analyze partition volume, identify major source-category contributors, and recommend partitioning opportunities.
- [SIEM detection source coverage analysis](7.SIEM_Detection_Source_Coverage_Analysis_Report.md) — Assess Cloud SIEM detection coverage and highlight observed and inferred gaps.

## Use a prompt

1. Open a prompt file in GitHub.
2. Select GitHub's **Copy raw file** button to copy the prompt text.
3. Start a new Mobot conversation and paste the text.

For Mobot instructions and help, see the [Mobot documentation](https://www.sumologic.com/help/docs/search/mobot/).
