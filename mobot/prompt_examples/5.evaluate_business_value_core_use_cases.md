# Executive Search Usage Report

Using the `_index=sumologic_search_usage_per_query` audit index, produce an executive report of Sumo Logic search usage for the last 7 days. Run each search as needed and synthesize the findings into a narrative report with supporting data tables.

## Field reference

Use these exact field names:

- `data_scanned_bytes` — total bytes scanned by the query
- `scanned_bytes_breakdown_by_metering_type` — JSON string containing per-tier byte breakdown
- `query_type`, `user_name`, `content_name`, `content_identifier`, `query`

## Tier detection

Run this first before Section 6 to detect which billing tiers are present in the org:

```sql
_index=sumologic_search_usage_per_query
| parse field=scanned_bytes_breakdown_by_metering_type "{*}" as breakdown
| parse regex field=breakdown "\"Continuous\"\s*:\s*(?<continuous_bytes>\d+)" nodrop
| parse regex field=breakdown "\"Infrequent\"\s*:\s*(?<infrequent_bytes>\d+)" nodrop
| parse regex field=breakdown "\"Flex\"\s*:\s*(?<flex_bytes>\d+)" nodrop
| parse regex field=breakdown "\"FlexSecurity\"\s*:\s*(?<flexsecurity_bytes>\d+)" nodrop
| where !isNull(continuous_bytes) or !isNull(infrequent_bytes) or !isNull(flex_bytes) or !isNull(flexsecurity_bytes)
| count as records by
    if(!isNull(continuous_bytes), "yes", "no") as has_continuous,
    if(!isNull(infrequent_bytes), "yes", "no") as has_infrequent,
    if(!isNull(flex_bytes), "yes", "no") as has_flex,
    if(!isNull(flexsecurity_bytes), "yes", "no") as has_flexsecurity
```

Use the result to determine the org's billing model:

- If `has_infrequent=yes`, this is a Tiered org. Infrequent is billable per TB scanned. Other tiers such as Continuous, CSE, and Frequent are free to scan.
- If `has_flex=yes` and `has_infrequent=no`, this is a Flex org. Only Flex bytes are billable per TB scanned.
- Note the active tiers and carry this context into Section 6.

## Section 6 — Billable scan analysis

Using the tier detection result from the preamble, parse `scanned_bytes_breakdown_by_metering_type` and extract only the billable tier bytes:

- Tiered orgs: extract `Infrequent` bytes (Continuous is not billable per scan)
- Flex orgs: extract `Flex + FlexSecurity` bytes (all are billable per scan)

Run:

```sql
_index=sumologic_search_usage_per_query
| parse field=scanned_bytes_breakdown_by_metering_type "{*}" as breakdown
| parse regex field=breakdown "\"Infrequent\"\s*:\s*(?<infrequent_bytes>\d+)" nodrop
| parse regex field=breakdown "\"Flex\"\s*:\s*(?<flex_bytes>\d+)" nodrop
| parse regex field=breakdown "\"FlexSecurity\"\s*:\s*(?<flexsecurity_bytes>\d+)" nodrop
| if(isNull(infrequent_bytes), 0, num(infrequent_bytes)) as infrequent_bytes
| if(isNull(flex_bytes), 0, num(flex_bytes)) as flex_bytes
| if(isNull(flexsecurity_bytes), 0, num(flexsecurity_bytes)) as flexsecurity_bytes
| eval billable_bytes = case(
    <ORG_IS_TIERED>, infrequent_bytes,
    <ORG_IS_FLEX>, flex_bytes + flexsecurity_bytes,
    true, 0
  )
| where billable_bytes > 0
| sum(billable_bytes) as total_billable_bytes,
  sum(infrequent_bytes) as total_infrequent,
  sum(flex_bytes) as total_flex,
  sum(flexsecurity_bytes) as total_flexsecurity,
  count as queries by query_type, user_name
| sort by total_billable_bytes desc
```

Replace `<ORG_IS_TIERED>` and `<ORG_IS_FLEX>` with the appropriate boolean condition based on the tier detection result.

If no results: note that all scans hit the non-billable tier (Continuous) only.

If results exist:

- Identify the top `query_type` and users driving billable scan cost
- Calculate each contributor's share of total billable bytes
- Cross-reference with Sections 2–5 to name the specific content items or workflows responsible
- Provide 3–5 concrete optimization recommendations ranked by estimated savings potential, such as:
  - Reduce scheduled search frequency
  - Add time-range guards to dashboard panels
  - Consolidate duplicate monitors
