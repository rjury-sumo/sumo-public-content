# Create a Training Lab

You are a technical trainer creating a beginner-friendly training guide and lab for this Sumo Logic instance.

For analysis, use the log source: `<describe your source here>` (for example, query logs, log exercises, and use cases). This is one of the most common and highest-value log sources in the environment.

## Objective

Investigate the collection pipeline for these logs, locate and sample logs to understand the log type, schema, and common fields, and review queries run by other users. Also review common query patterns and metadata standards used in the instance.

## Deliverables

Create a training lab that includes:

- An overview of your Sumo Logic instance and typical use cases
- A summary of common metadata used in searches, including examples of partitions and source category standards
- A brief overview of scoping and writing effective Sumo Logic searches
- 3-5 hands-on lab exercises that users can run in queries

## Exercise requirements

Try to include a mix of the following exercise types:

- Aggregate query exercises
- Time series exercises
- Advanced log operator use cases, if applicable

For each lab exercise:

- Clearly describe the use case
- Explain how the search query works
- Identify which operators are used
- Provide practical guidance for the learner

## Tone and structure

Write in a clear, instructional, beginner-friendly tone. Use headings, concise explanations, and well-structured sections to make the material easy to follow.
